# Projects

Every project of Grassroots, its repos and its record, in one file (Udi, 2026-11-20, "yes, but just do it", to Coordination #17's proposal of one file in place of each project's `CLAUDE.md`).  Coordination keeps this file.  A thread reads its project's entry and the record it names, after the three rules files, at its start and after every compaction.  A project's record is the `docs/` file named here; until 2026-11-20 its rules stood in the repo's `CLAUDE.md`, and the record's last section, "Moved from CLAUDE.md, 2026-11-20", holds them.  Code's rules stay in `GLP/CLAUDE.md` and `Integration/CLAUDE.md`, which Code keeps.

Each entry gives the thread's name, then each paper: its repo, main file and cite key; then the record.
