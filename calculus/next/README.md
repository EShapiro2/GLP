# The contracts of the Calculus's next publication, before their cascade run

For a test of the site, and for nothing else: this is not a publication, and no owner adopts from it.  It is printed from the Calculus's code at ed9032e7, 2026-11-16.

66 contracts: the 62 on `main`, five of them renamed (AGORA is Agora, JOINT is Joint, STAY is Stay, LIB is Lib, REC is Rec), and four new: CDC, GN, GS and GA.

One directory for each contract, with the files a publication has under the same names: `contract.txt`, the contract; `logic-pragmas.txt`, the contract with its Logic pragmas; `schemas.txt`, its speech-act schemas; `full-contract.txt`, the contract with the operations of its first line and of its citations applied; `full-pragmas.txt` and `flat.txt`; `full-schemas.txt`, the expanded schemas.

`LAYERS.txt` is the order of the contracts by what each is written from; `OWNERS.md` each contract's owner; `relations.txt` a verdict for each relation a first line states.

Not here, since the run is not in: `term.glp.txt`, `verdict.txt`, `vmat.tex`, `interface.txt`, `platform.vglp`, `platform.glp`, `STATE.txt`.  The publication will have them.
