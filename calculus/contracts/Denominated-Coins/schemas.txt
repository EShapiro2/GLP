Denominated Coins
Denominated Coins lifts Coins, and extends and weakens it.
Vocabulary: x has issued coins of the denomination f = issued_in(x,f); x holds an f-denominated y-coin = coin(x,y,f); x holds n f-denominated y-coins = coin(x,y,f,*n); x holds exactly n f-denominated y-coins = coin(x,y,f,#n); z holds n f-denominated w-coins in escrow from x for y on k = escrow_coin(z,w,f,x,y,k,*n).
After x issues n f-denominated x-coins for the first time: x holds n f-denominated x-coins and x has issued coins of the denomination f.
