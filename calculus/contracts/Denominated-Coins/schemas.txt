Denominated Coins
Denominated Coins lifts Coins, and extends and weakens it.
Vocabulary: x has issued coins of the denomination f = issued_in(x,f); x holds n f-denominated y-notes of type t = note(x,y,t,f,*n); z holds n f-denominated w-notes of type t in escrow from x for y on k = escrow_note(z,w,t,f,x,y,k,*n); x holds an f-denominated y-coin = note(x,y,coin,f); x holds n f-denominated y-coins = note(x,y,coin,f,*n); x holds exactly n f-denominated y-coins = note(x,y,coin,f,#n); z holds n f-denominated w-coins in escrow from x for y on k = escrow_note(z,w,coin,f,x,y,k,*n).
After x issues n f-denominated x-coins for the first time: x holds n f-denominated x-coins and x has issued coins of the denomination f.
