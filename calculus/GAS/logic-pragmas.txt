GAS: Grassroots App Store
GAS composes GPD with GSV (GNA, GLP Networking API and Services, in preparation) and extends the composition.
A *store* is a service holding a list of programs. Alice *trusts* a store when she has declared it and has not withdrawn the declaration.
Alice, Bob and Carol are persons, Dave a service.
1. ■ Open store: Carol may make Dave a store, provided Carol is a guardian of Dave.
2. ○ Listing. List: Carol may list in Dave a program of Bob, provided Carol is a guardian of Dave, Dave is a store and Carol trusts Bob as a developer. Carol lists it after adding her signature to its signatures. Delist: Carol may delist from Dave a program of Bob, provided Carol is a guardian of Dave. Carol will delist it if she ceases to trust Bob as a developer.
3. ■ Store trust. Trust store: Alice may declare trust in Dave, provided Carol is a guardian of Dave and Alice knows Carol. Untrust store: Alice may withdraw her declaration of trust in Dave.
4. ■ Install from store: Alice may install from a store a program of Bob, provided Dave lists a program of Bob and Alice trusts the store Dave.
Logic pragmas.
Vocabulary: d is a store = store(d); d lists a program of y = lists_program(d,y); x trusts the store d = trusts_store(x,d).
After x makes d a store, which requires d is not a store: d is a store.
After x lists in d a program of y, which requires d does not list a program of y: d lists a program of y.
After x delists from d a program of y: no longer d lists a program of y.
After x declares trust in d, which requires x does not trust the store d: x trusts the store d.
After x withdraws x's declaration of trust in d: no longer x trusts the store d.
After x installs from a store a program of z, which requires x does not have a program of z installed: x holds a program of z and x has a program of z installed.
