GPD: Grassroots Programs Dissemination
GPD extends GFP (GSC, From Grassroots Contract to Grassroots App, https://arxiv.org/abs/2609.06231).
A *program* is an item: compiled code, signed by its compiler, that gives the grassroots contract it is compiled from, its clauses and its speech-act schemas; its *developer* is its author. Alice *trusts* Carol *as a developer* when she has declared it and has not withdrawn the declaration.
Alice, Bob, Carol and Dave are persons, Carol and Dave possibly Alice, Bob or one person.
1. ◆ Publish: Carol may publish a program by signing it. Carol attests that its schemas say what its clauses say, that it is the result of compiling the schemas, and that it is expected to behave correctly according to the contract.
2. ■ Developer Trust. Trust: Alice may declare trust in Carol as a developer, provided Alice knows Carol. Untrust: Alice may withdraw her declaration of trust in Carol as a developer.
3. ■ Offer: Carol may offer a program of Dave to Alice, provided Carol holds a program of Dave and Carol and Alice are friends. Carol offers it by forwarding it to Alice.
4. ■ Install own: Alice may install her own program, provided Alice holds a program of Alice. Install: Alice may install a program of Carol, provided Alice holds a program of Carol and Alice trusts Carol as a developer.
5. ■ Invite: Alice may invite Bob to join in a program of Carol, with the consent of Bob, provided Alice and Bob are friends, Alice has a program of Carol installed and Bob trusts Carol as a developer. Bob then has the program installed, with Alice's signature added, and each is a participant of the program with the other.
6. ■ Leave: Alice may leave a program of Carol.
Logic pragmas.
Vocabulary: x holds a program of y = program(x,y); x trusts y as a developer = trusts_developer(x,y); x has a program of y installed = installed(x,y); x is a participant of a program of z with y = participant(x,z,y).
x has no participation in a program of z: x is a participant of a program of z with no one and no one is a participant of a program of z with x.
After x publishes a program by signing it: x holds a program of x.
After x declares trust in y as a developer, which requires x does not trust y as a developer: x trusts y as a developer.
After x withdraws x's declaration of trust in y as a developer: no longer x trusts y as a developer.
After x offers a program of z to y: y holds a program of z.
After x installs x's own program, which requires x does not have a program of x installed: x has a program of x installed.
After x installs a program of z, which requires x does not have a program of z installed: x has a program of z installed.
After x invites y to join in a program of z: y holds a program of z, y has a program of z installed, x is a participant of a program of z with y and y is a participant of a program of z with x.
After x leaves a program of z: no longer x has a program of z installed and x has no participation in a program of z.
