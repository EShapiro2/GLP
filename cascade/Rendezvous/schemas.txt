Rendezvous
Rendezvous extends Services.
Vocabulary: d is a rendezvous server = rendezvous_server(d); x has signed n as an invitation link that names d = link(x,n,d); d has n registered for x = registered(d,n,x); d holds n expired = expired(d,n); d holds n spent for x = spent(d,n,x); x has the address of y = address(x,y); d has the signature of y over the friendship of x and y presented = presented(d,x,y).
After x makes d a rendezvous server, which requires d is not a rendezvous server: d is a rendezvous server.
After x signs n as an invitation link that names d, which requires x has not signed n as an invitation link that names d: x has signed n as an invitation link that names d.
After x registers n with d, which requires d does not have n registered for x: d has n registered for x.
After y presents n of x to d: no longer d has n registered for x, d holds n spent for x, x has the address of y and y has the address of x.
After x presents to d the signature of y over the friendship of x and y, which requires d does not have the signature of y over the friendship of x and y presented: d has the signature of y over the friendship of x and y presented.
After d matches x and y: no longer d has the signature of y over the friendship of x and y presented, no longer d has the signature of x over the friendship of y and x presented, x has the address of y and y has the address of x.
Rendezvous:0 - | An *invitation link* of Alice's is a term she signs, naming her, a rendezvous server, a serial and an expiry.
Rendezvous:0 - | Alice, Bob and Carol are persons, Dave a service, Link an invitation link.
Rendezvous:1 ■ Open server: rendezvous_server(Dave) <- guardian(Carol,Dave), ~rendezvous_server(Dave) guarded by Carol.
Rendezvous:2 ■ | Invite by link.
Rendezvous:2 ■ Sign link: link(Alice,Link,Dave) <- knows(Alice,Dave), ~link(Alice,Link,Dave) guarded by Alice.
Rendezvous:2 ■ Invite by link: registered(Dave,Link,Alice) <- link(Alice,Link,Dave), knows(Alice,Dave), rendezvous_server(Dave), ~spent(Dave,Link,Alice), ~registered(Dave,Link,Alice) guarded by Alice.
Rendezvous:2 ■ | Link has a new serial.
Rendezvous:3 ■ Use link: ~registered(Dave,Link,Alice), spent(Dave,Link,Alice), address(Alice,Bob), address(Bob,Alice) <- knows(Bob,Dave), ~expired(Dave,Link), registered(Dave,Link,Alice) guarded by Bob.
Rendezvous:3 ■ | The link is then spent.
Rendezvous:4 ■ | Reconnection.
Rendezvous:4 ■ Present: presented(Dave,Alice,Bob) <- friend(Alice,Bob), friend(Bob,Alice), knows(Alice,Dave), rendezvous_server(Dave), ~presented(Dave,Alice,Bob) guarded by Alice.
Rendezvous:4 ■ Match: ~presented(Dave,Alice,Bob), ~presented(Dave,Bob,Alice), address(Alice,Bob), address(Bob,Alice) <- presented(Dave,Alice,Bob), presented(Dave,Bob,Alice).
