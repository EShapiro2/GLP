Coins
Coins extends Notes.
Vocabulary: x holds a y-coin = note(x,y,coin); x holds n y-coins = note(x,y,coin,*n); x holds exactly n y-coins = note(x,y,coin,#n); z holds n w-coins in escrow from x for y on k = escrow_note(z,w,coin,x,y,k,*n).
After x pays the issuer y n y-notes of type t: no longer x holds n y-notes of type t and y holds n y-notes of type t.
After x redeems a y-coin against a z-coin: no longer x holds a y-coin, y holds a y-coin, no longer y holds a z-coin, x holds a z-coin and x knows z.
Coins:0 - | A *coin* is a note that is a unit of its issuer's debt. An *Alice-coin* is a coin issued by Alice.
Coins:0 - | Alice, Bob and Carol are parties, Sum a number, Carol possibly Alice or Bob.
Coins:1 ■ Pay issuer: Notes:3 relaxed; one Carol=Bob; without the consent of Bob <-.
Coins:2 ■ Redeem: ~note(Alice,Bob,coin), note(Bob,Bob,coin), ~note(Bob,Carol,coin), note(Alice,Carol,coin), knows(Alice,Carol) <- knows(Alice,Bob), note(Alice,Bob,coin), note(Bob,Carol,coin) guarded by Alice possibly Alice=Carol, Bob=Carol.
