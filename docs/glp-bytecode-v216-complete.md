# GLP Bytecode Instruction Set Specification

**Retired 2026-07-04 (paper-and-code discipline).** The normative sources are the IGLP paper's code-format appendix `app:code-format` (opcode table, operands, encoding, artefact, loader), its Implementation Notes appendix (heap model, clause try, scheduling), the companion GLP paper for the language semantics the instructions realise, the FCP sequential abstract machine (Houri and Shapiro) for the machine design, and the implemented runner in `glp_runtime`. Full text (v2.16.3, 88KB) recoverable from git; note its variable-model sections predate the pointer heap and were superseded before retirement.
