# ICLP GLP

## Mission

Write the GLP paper for ICLP (International Conference on Logic Programming).

## Scope

- GLP language design and semantics
- SRSW (Single Reader Single Writer) constraint
- Concurrent logic programming foundations
- Type system overview
- Multiagent applications

## Paper Structure (Draft)

1. **Introduction** - GLP motivation, contributions
2. **Language** - Syntax, semantics, SRSW
3. **Type System** - Moded types, SRSW verification
4. **Implementation** - Runtime, compiler
5. **Applications** - Social graph, multiagent protocols
6. **Related Work** - FCP, concurrent LP history
7. **Conclusion** - Future work
