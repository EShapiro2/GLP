## How a change reaches the site

Push it to the branch `GSA-site` of GLP; the hourly sweep, at eleven minutes past the hour, shows it at `/test`; ask Udi; on his yes ask Code, `To: Code`, to merge the branch into main, quoting his words, since Code's permission check takes a merge to main of the site as a deploy and asks for his word to Code too.  Only the site's own session pushes `GSA-site`: what is pushed there runs on the server as `glp` before anyone reads it.  `deploy/test.sh` names the branch, `TEST_BRANCH`; rename it there if the project's branch is renamed.  A fix to the live site that is no change of design, as of a fault, goes on the project's branch for main and to Code.  The server is Code's to reach: a sweep at once, a deploy and the server's log are asked of Code by mail.
