# Session 3: Book Program Conversion
**Date:** 2026-01-16
**Goal:** Convert programs from book/ to typed_book/ with type annotations

---

## Mission

Convert untyped programs to typed GLP by:
1. Adding type declarations
2. Adding procedure type annotations
3. **Presenting conversion to USER for approval**
4. After approval: saving OR escalating bugs to Session 1

## Workflow

1. Pick a program from book/
2. Add type declarations and annotations
3. Type check it
4. **PRESENT TO USER - WAIT FOR APPROVAL**
5. After approval: Save OR fix OR hand to Session 1

## CRITICAL: Present conversions in this format

```
CONVERSION: [program name]

Original: [book/ filepath]
Converted: [typed_book/ filepath]

Type Check Result: [PASS/FAIL]
Changes: [list what you added]

Awaiting approval to save.
```
