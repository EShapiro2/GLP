Notes
Notes extends Knowledge.
A *note* includes its issuer's public key, is signed by their private key, and gives its holder a right against its issuer. An *Alice-note* is a note issued by Alice.
Alice, Bob and Carol are parties.
1. ■ Issue: Alice may issue Alice-notes.
2. ■ Swap: Alice and Bob, who know each other, may jointly swap notes they hold.
3. ■ Pay: Alice may pay notes she holds to Bob, whom she knows, with his consent.
4. ○ Escrow. Deposit: Alice may deposit notes with Carol for Bob, on a condition the three agree, with the consent of Carol. Release: Carol and Bob may jointly release them to Bob. Return: Carol and Alice may jointly return them to Alice. Carol will release them only if the condition is met, and return them only if it fails. Each act is between two parties who know each other.
Logic pragmas
Notes extends Knowledge.
A *note* includes its issuer's public key, is signed by their private key, and gives its holder a right against its issuer. An *Alice-note* is a note issued by Alice.
Alice, Bob, Carol and Dave are parties, Cond a condition Alice, Bob and Carol agree, Sum and Total numbers, Type and Other types; in clause 2 Carol and Dave are possibly Alice, Bob or one person, in clause 3 Carol is possibly Alice or Bob, and in clause 4 Dave is possibly Alice, Bob or Carol.
1. ■ Issue: Alice may issue Sum Alice-notes of type Type.
2. ■ Swap: Alice and Bob may jointly swap Sum Carol-notes of type Type for Total Dave-notes of type Other, provided Alice and Bob know each other.
3. ■ Pay: Alice may pay Bob Sum Carol-notes of type Type, with the consent of Bob, provided Alice knows Bob.
4. ○ Escrow. Deposit: Alice may deposit Sum Dave-notes of type Type with Carol for Bob on Cond, with the consent of Carol, provided Alice and Carol know each other and Alice knows Bob. Release: Carol and Bob may jointly release Sum Dave-notes of type Type that Alice deposited on Cond, provided Carol and Bob know each other. Return: Carol and Alice may jointly return Sum Dave-notes of type Type deposited for Bob on Cond, provided Carol and Alice know each other. Carol will release them only if Cond is met, and return them only if it fails.
Logic pragmas.
Vocabulary: x holds n y-notes of type t = note(x,y,t,*n); z holds n w-notes of type t in escrow from x for y on k = escrow_note(z,w,t,x,y,k,*n).
After x issues n x-notes of type t: x holds n x-notes of type t.
After x and y swap n z-notes of type t for m w-notes of type u: no longer x holds n z-notes of type t, y holds n z-notes of type t, no longer y holds m w-notes of type u, x holds m w-notes of type u, y knows z and x knows w.
After x pays y n z-notes of type t: no longer x holds n z-notes of type t, y holds n z-notes of type t and y knows z.
After x deposits n w-notes of type t with z for y on k: no longer x holds n w-notes of type t and z holds n w-notes of type t in escrow from x for y on k.
After z and y release n w-notes of type t that x deposited on k: no longer z holds n w-notes of type t in escrow from x for y on k, y holds n w-notes of type t and y knows w.
After z and x return n w-notes of type t deposited for y on k: no longer z holds n w-notes of type t in escrow from x for y on k, x holds n w-notes of type t and x knows w.
Interface pragmas
Notes: the notes Alice holds.
Issue: Alice [Issue] <type> <amount>
Swap: Alice [Swap] <amount given> <issuer wanted> <type wanted> <amount wanted>
  Bob: Alice asks to swap notes with you.
Pay: Alice [Pay] <amount>
  Bob: Alice asks to pay you notes.
Escrow: Alice [Deposit] <amount> <condition>
  Carol: Alice asks to deposit notes with you.
  Carol [Release] <amount>
  Bob: Carol asks to release notes to you.
  Carol [Return] <amount>
  Alice: Carol asks to return notes to you.
