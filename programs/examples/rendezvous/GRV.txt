GRV: Grassroots Rendezvous
GRV extends GSG (GSC, From Grassroots Contract to Grassroots App, https://arxiv.org/abs/2609.06231).
Alice, Bob and Carol are persons.  A rendezvous server is a machine of Carol's at an address every person can reach.  An invitation link is a term Alice signs, naming Alice, a rendezvous server, a serial and an expiry.
1. ■ Server.  Carol may set up a rendezvous server.
2. ■ Registration.  Alice may register with Carol's server an invitation link she signed that names the server, with a serial she has not registered with it before.
3. ■ Redemption.  Bob may present to Carol's server an invitation link registered with it that has not expired; the server then gives Alice Bob's address and Bob Alice's, and the link is spent.
4. ■ Reconnection.  Alice and Bob, who are friends, may each present to Carol's server the other's signature over their friendship; the server then gives each the address of the other.
Implementation pragmas
Redemption, Reconnection: the address of a person is the one at which the server's networking layer observes them, read by peer_address/2; a person given an address punches towards it by punch_udp/1, and the smaller key initiates.
Registration: an invitation link expires an hour after it is made.
